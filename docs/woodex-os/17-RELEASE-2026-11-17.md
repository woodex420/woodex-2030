# WOODEX OS — release report, 17 November 2026

The first report in the form of document 10 §9 (list line T-170). Its ten headings are that document's ten
points; `scripts/verify-acceptance.mjs` refuses a release report without them.

**What went out, and on whose word.** On 17 November the owner lifted the holds: "this is not private data, this
is Woodex data"; "unfreeze, unblock, everything, to start production-ready deployment" (decision DL-022). Under
that word:

| | What | State |
|---|---|---|

| 2 | The React shop's database: Supabase's Data API closed, catalogue migration 019 applied, three rows of the migration ledger corrected | Done and read back (DL-024) |
| 3 | The acceptance scenarios, the browser flows, the gates, a sheet per module and the defect register, kept true by a check in CI | In the code (document 16) |
| 4 | Pull request #36 merged into `main`, from which Vercel rebuilds the React shop and the hosted workspace | The last step of the round; recorded on the pull request |

**What did not go out.** No product was published anywhere. No customer, lead or order was moved. Nothing was
installed on Hostinger. The React shop still sells its 148 sample products: replacing them is three actions in
the old dashboard, which needs the owner's sign-in (line T-091).

## 7. Backup/restore status

**No backup was taken before the database was changed, and none has been restored.** Whether the Supabase plan
keeps backups was not checked. This is defect D-011 and line T-187. What stands in for it today:

| Change | The way back |
|---|---|
| Privileges taken from the API roles | The four `GRANT` lines at the head of `deploy/supabase/2026-11-17-close-data-api.sql` |
| Migration 019 | `scripts/migrations/rollback/019_catalogue.rollback.sql`, and the removal of ledger row 19 |
| Ledger rows 16 to 18 | Their old values: `016_support` with `sha256:696ffe6e3cfc024b`; `017_credentials` and `018_throttle`, each with `sha256:` before the checksum it has now |
| The hosted workspace | The earlier deployment, kept by Vercel |
| The data itself | The 148 products are those of the seed file `apps/api/seed-data.json`; nothing else of value is in the database yet |

That stops being enough with the first real order. The Laravel admin holds no real record, so it has nothing to
back up yet; its backups are proven on Hostinger (T-137).
