## 8. Performance observations

In CI, on Apache and MariaDB: a release is put together in 9 seconds; the whole installation journey, nine steps
with the creation of 125 tables, takes 8 seconds; the journey after a deployment 3 seconds; the job 2 min 20 s. In
the sandbox the installation itself takes 3 to 4 seconds on SQLite. The three database servers need about the
same time for the suite (the longest group 115 to 143 seconds). **None of this says how fast the admin is on
Hostinger's shared hosting** (T-139).
