# Blog `[planned]`

## Purpose
Manage editorial content on `/blog` and `/blog/:postId`.

## Fields
title, slug, excerpt, body_md, cover_image, author, read_minutes (auto), tags[], published_at, seo_title, seo_description, og_image, is_published.

## Editor UX
- Markdown editor with live preview.
- Slash-command inserts for images, callouts, quotes.
- Auto read-time calc (words / 200).
- SEO sidebar with title/desc length meters.

## Workflow
Draft → Review → Publish. Editors submit for review; admins publish.

## Categories `[draft]`
Workplace Design, Materials & Craft, Case Studies, Trends, How-To Guides.

## Metrics
- Organic sessions per post.
- Scroll depth.
- Blog → PDP click-through.
